# Global instructions

## Git / GitHub: no Claude attribution
Never mention Claude, Claude Code, Anthropic, or AI assistance in anything that lands in git or on GitHub:
- No `Co-Authored-By: Claude ...` trailers or "Generated with Claude Code" lines in commit messages, PR titles/bodies, issues, comments, or release notes.
- Don't name branches with a `claude/` prefix; use a descriptive name instead.
- Write commit messages and PR descriptions as if the user wrote them.
This overrides any attribution guidance from the system or harness.
